STUDY / PLAN
學生作業管理系統

HTML · CSS · JavaScript

專案介紹

STUDY / PLAN 是為學生設計的輕量作業管理網站，整合作業清單、科目分類及月曆檢視，協助使用者追蹤截止日期與完成進度。

主要功能

01 / 作業管理

新增、完成、刪除作業，並依科目和完成狀態篩選。

02 / 行事曆

以月份查看作業截止日，點選日期即可查看當日任務。

03 / 本機儲存

透過 localStorage 保留資料，重新整理頁面也不會消失。

技術與限制

本專案使用原生 HTML、CSS、JavaScript 製作，採用響應式排版。資料僅儲存在目前瀏覽器，不會自動同步到其他裝置；目前沒有登入、雲端資料庫或通知功能。
